안건) 포렌식 모델 오답 유형 분석 및 도식화

오답 유형 분류: 기존 7개 유형을 4개(Tool, Parsing, Discovery, Reasoning)로 통합하여 분석 체계 정립.
도식화 필요성: 각 유형별 실패 지점을 시각화하여 모델의 기술적 한계(도구/파서 문제)와 모델 자체의 추론 한계를 명확히 구분할 것.
분석 방향: 
단순 기술적 오류(Tool/Parsing)는 권한 부여 및 파서 보완으로 해결 가능한지 검증.
Discovery/Reasoning 오류는 사람의 의사결정 과정(키워드 검색, 필터링 등)과 비교하여 모델의 추론 패턴 분석.

데이터셋 정제 및 통계 분석
두 명의 연구자가 수행한 결과를 통합하고 데이터셋 정제.
데이터 항목 추가: '오답 횟수' 열을 추가하여 1회/2회 오답 여부를 구분하고, 반복적으로 틀리는 문제에 대한 심층 분석 수행.
힌트 유형 검증: 힌트가 실제 정답 복구에 효과적인지, 힌트 유형(Locator, Oracle 등)이 오답 유형과 적절히 매칭되었는지 검토.

향후 연구 계획
모델 확장: 현재 사용 중인 Claude 5.5 Opus 외에 추가 모델(HAI-GPT:GEMMA-Antigravity)을 활용한 비교 분석 고려.
논문 작성: 연구 결과를 바탕으로 데이터 포렌식 관련 학회 투고 준비.

조치 사항
오답 유형 통합 및 데이터셋 재정리: 오답 문항 전체 정리, 오답 횟수 열 추가 
오답 유형별 도식화 자료 작성: 모델의 실패 지점을 명확히 보여주는 그림 및 통계 자료 생성
힌트 유형 및 효과성 분석: 힌트 제공이 실제 정답률에 미치는 영향 및 힌트 프롬프트의 구체성 비교 분석
API 연동 및 추가 모델 테스트: Antigravity을 활용한 추가 모델 테스트 환경 구축
